# WellFit-now Do Not Assume

Revalidate these facts before relying on them:
- current runtime/branch/commit state;
- Firebase/Supabase/provider configuration and external approvals;
- build/deploy status from a previous session;
- that an implementation is accepted merely because code exists;
- that a visual/native task belongs in this repository;
- that historical TODOs override current tested runtime behavior or protected canonical truth.

When work depends on a drift-prone fact, record the revalidation in `EVIDENCE.md`, `CURRENT_STATE.md` or the related task.
