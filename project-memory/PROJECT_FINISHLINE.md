# WellFit-now Finishline

Human-readable finishline for the technical web/backend repository.

## Gates
- Registration/auth/consent
- Account lifecycle/privacy
- Backend/runtime readiness
- Server-authoritative rewards/missions/economy boundaries
- Cross-repository contract readiness

Machine state lives in `FINISHLINE_STATE.json`.

## Rules
- Implementation is not runtime/provider acceptance.
- Native AR/buddy work remains owned by WellFit-Buddy until explicitly migrated.
- Visual/landing work remains owned by WellFit until explicitly migrated.
- Convergence of the three repositories is planned but not scheduled.
