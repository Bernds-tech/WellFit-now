## Classification rule

These files are product, strategy, finance, audience, health, avatar, execution, presentation, whitepaper or token/presale sources. They are not executable specifications and are not current runtime authority.

Where they mention WFT, Solana, SUI, blockchain, token sales, NFTs, financial forecasts, medical/health outcomes or minors, the content remains historical or review-required until a separately approved legal, financial, privacy, medical and technical validation exists.

## Reconciled decisions

- The durable product core is movement, learning, missions, Buddy motivation, internal progression and later community/AR expansion.
- Internal points and XP must work safely before any blockchain or transferable economy.
- Beta-1 does not activate WFT, SUI, Solana, wallets, presale, NFTs, trading, staking, payouts or cash-out.
- Financial scenarios are hypotheses, not verified forecasts or investor claims.
- Health and weight-related content must avoid diagnosis, shame, pressure and unvalidated outcome promises.
- Family/minor functionality requires guardian, consent, data-minimization, safety and app-store review before release.
- Avatar/Buddy concepts should extend the existing Buddy system rather than introduce a second profile/economy authority.

## How to reuse these sources without duplicate work

1. Link a new backlog item to the relevant source row.
2. Search current code, `project-register/`, `docs/` and `todolist/` for an existing owner.
3. Mark the item as already implemented, partially implemented, planned, blocked or superseded.
4. Create a new system only if the existing architecture cannot safely own it and that decision is recorded.
5. Keep commercial/token/health/minor claims out of public runtime until their dedicated reviews are complete.

## KI-Fortsetzungs-Prompt

Use these 16 sources as historical product input, not current runtime truth. Before importing an idea, compare it with current code, the protected Beta-1 Canonical Truth, the runtime state and the execution board. Do not revive WFT/Solana/SUI/blockchain/presale/NFT/cash-out or unverified health/financial/minor claims. Extend an existing WellFit module and record the source link and implementation status.
